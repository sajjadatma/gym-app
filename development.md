# Local development

Use the root [`README.md`](README.md) for first-time setup and the commands to run PostgreSQL, Mailpit, FastAPI and Vite locally.

Key local URLs:

- Frontend dev server: <http://localhost:5173>
- FastAPI: <http://localhost:8000>
- Mailpit: <http://localhost:8025>

The approved MVP1 target is local development/manual acceptance only. Do not deploy this repository as part of MVP1.

See [`docs/local-testing.md`](docs/local-testing.md) for demo accounts and acceptance walkthroughs, and [`docs/implementation-progress.md`](docs/implementation-progress.md) for the verification checklist.
